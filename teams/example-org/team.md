# Example Organization

Teams nest to any depth. A folder under `teams/` (or under another team) that contains a `team.md` is a team; its id is its path, for example `example-org/division-a`. `level` is free text, so use whatever your organization calls each tier (directorate, center, department, group, division, branch, ...). Delete the `example: true` line in your own copy.

Tags defined here are visible to every team below it.
