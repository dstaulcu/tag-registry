# Ideas

Starting points, from simple to ambitious.

- **Weekly review by area.** Filter a week of daily notes by `#area/home` and `#area/work` to see where time went.
- **Objective rollups.** Have a scheduled agent collect every note tagged `#objective/<name>` and write a status page for the person who owns that goal. The `Related:` line in an objective note lists the projects that serve it.
- **Technique communities.** Search `#technique/<name>` across vaults to find who has done something before.
- **Relationship tracking.** Pair `#with/<party>` with `#technique/relationship-building` to see where effort to build a relationship has gone.
- **Onboarding.** Give a new team member the team folder. Their tag autocomplete is the team's vocabulary on day one.
- **Autocomplete and linting.** An editor plugin or CI step that warns on a tag not in `registry.json`, or one that is `deprecated` and names a `replaced_by`.
- **Private mirror.** Run an internal registry in the same format behind authentication, and subscribe to it beside the public one.
- **Personal registry.** Keep your own tags in a repo of your own using the same layout, so nothing personal lands in a shared one.
- **Agent prompts.** Give an agent the `definition` lines for the tags it should use, so it tags consistently with you.
- **Hierarchy dashboards.** Use `parent` and `level` to roll up from a branch to a division to the whole organization.
