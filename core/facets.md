# Facets

Every tag is `<facet>/<name>`. The core defines the facets; teams add values under them. Propose a new facet to the core group.

- `area`: the life domain the effort belongs to (home, work, health, fitness, finance, learning). Keep the list small and use one per note or bullet.
- `with`: who the effort involves. Core holds generic kinds (family, team, customer); named people and organizations belong in a team folder, not core.
- `project`: a project or initiative, including bounded efforts such as a trip. The facet is core; values are owned by teams.
- `technique`: a capability or method, named by capability and not by tool. Use `technique/relationship-building` with a `with/` tag for relationship effort.
- `tool`: a product or project name.
